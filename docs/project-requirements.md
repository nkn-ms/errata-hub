## プロジェクト概要

書籍に関する読者からのフィードバック（誤字脱字・正誤情報・読みやすさの気になる点）を受け付け、
出版社に連絡・回答を管理するWebアプリケーション。

### フェーズ
- **フェーズ1**：自分が読んだ技術書の誤字脱字投稿ツールとして運用
- **フェーズ2**：一般ユーザーも使えるフィードバックサービスに拡大

最初から書籍全般（技術書・一般書）対応で設計する。

---

## ユースケース

```
読者 → フォームで入力 → [管理者（自分）] → 出版社にメールで連絡 → 出版社が回答 → 読者に通知
```

## 決定済み

### フィードバックの種類
- 誤字脱字・正誤情報（例：「わたし」→「私」）
- 気になる点（読みにくい、わかりにくいなど）
- その他の改善提案

### ユーザー管理
- 会員登録・ログイン機能あり
- 管理者（自分）も使う
- 一般ユーザーも登録して利用可能

### 管理画面（ダッシュボード）
- テーブル形式で問い合わせ一覧を表示
- 出版社の回答をカラムに直接入力できる
- ステータス管理（未対応 / 確認中 / 回答済み / 修正予定 / 対応不要）
- 出版社別フィルタ

### メール通知
- 現在：管理者が手動でメール送信（読者をCCに含める）
- 将来：自動メール送信に移行予定

### フォルダ名
- `errata-hub`

### 画面一覧

#### 読者向け（公開側）

| 画面 | 内容 | ログイン要否 |
|------|------|------------|
| トップページ | 投稿されたフィードバック一覧テーブル（誰でも閲覧可）、ヘッダーにログインボタン | 不要 |
| 会員登録 | メール・パスワード登録 | 不要 |
| ログイン | メール・パスワードでログイン | 不要 |
| フィードバック投稿 | 書籍検索（サジェスト）＋フィードバック入力フォーム | 必要 |
| 投稿履歴一覧 | 自分の投稿一覧・ステータス確認 | 必要 |
| 投稿詳細 | 投稿内容＋出版社の回答確認 | 必要 |

**一覧テーブルのカラム**（トップページ）
- 書籍名 / 概要 / 誤→正（または内容要約）/ 出版社からの回答 / 位置 / 種別 / ステータス / 投稿日
- 行クリック → その書籍の投稿一覧画面へ

**書籍別投稿一覧画面**
- 選択した書籍に対する全フィードバック一覧
- ここから個別の詳細画面へ

**詳細画面の表示内容**
- 書籍情報（表紙画像・書籍名・著者・出版社）
- 誤→正（または該当箇所・コメント）
- 位置情報（ページ・行・位置備考 または Kindle位置）
- 添付画像
- 備考
- 出版社の回答

#### 管理者向け

| 画面 | 内容 |
|------|------|
| 管理ダッシュボード | 全問い合わせ一覧・フィルタ・ステータス管理 |
| 問い合わせ詳細 | 内容確認＋出版社回答入力 |
| 出版社マスタ管理 | 出版社の追加・編集・メールアドレス管理 |
| ユーザー管理 | 登録ユーザー一覧 |

## 技術スタック
- フレームワーク: Next.js (App Router)
- DB・認証: Supabase（PostgreSQL + Auth）
- ORM: Prisma
- UIコンポーネント: shadcn/ui + Tailwind CSS
- テーブル: TanStack Table（フィルタ・ソート・ページネーション）
- メール: 当面は手動（Outlookから送信）、将来的に Resend で自動化予定
- デプロイ: Vercel（無料）

### 入力フォームの項目
#### 書籍情報（API連携・サジェスト入力）
- 書籍名（Google Books API でサジェスト）
- 著者名（自動入力）
- 出版社名（自動入力）
- ISBN（自動入力）
- 書影画像（自動取得）
- 書籍詳細は OpenBD で補完

#### フィードバック内容
- 概要（投稿の一行要約・例：「p.42 誤植：わたし→私」）
- 種別（誤字脱字 / 正誤情報 / 読みにくい・わかりにくい / その他）
- 位置情報（種別で切り替え）
  - ページ：ページ番号（必須）・行番号（任意）・位置備考（任意・例：「ページ中央の図」）
  - Kindle・電子書籍：位置（自由入力・例：「43%」「Location 1234」）
  - その他：位置メモ（自由入力）
- 誤・正（誤字脱字 / 正誤情報 のとき）
- 該当箇所・コメント（気になる点 / その他 のとき）
- 画像添付（任意・該当箇所の写真やスクリーンショット）← Supabase Storage に保存
- 備考（全体的な補足・任意）

#### 報告者情報
- 会員登録情報から自動取得（名前・メールアドレス）

### 出版社管理
- 出版社マスタをシステムで管理する
- 最初は空、問い合わせが来たタイミングで管理者が追加する運用
- 将来の自動メール送信に備えて担当者メールアドレスも登録できる

### 読者への通知タイミング
- 当面は管理者が手動でOutlookからメール送信（読者をCCに含める）
- 将来：管理画面に「読者に通知する」ボタンを追加（Resend実装後）
