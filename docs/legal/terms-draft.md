# Errata Hub 利用規約

本利用規約（以下「本規約」といいます）は、個人として本サービスを運営する nkn-ms（以下「運営者」といいます）が提供する「Errata Hub」（以下「本サービス」といいます）の利用条件を定めるものです。利用者（以下「ユーザー」といいます）は、本規約に同意のうえ本サービスを利用するものとします。

## 第1条（本サービスの概要）

1. 本サービスは、技術書をはじめとする出版物について、読者が発見した**正誤情報（誤字・脱字・記載の誤り等）および改善提案（より分かりやすい表現の提案等）、その他の気づき**を投稿し、共有するための公開型のユーザー投稿サービスです。
2. 投稿には、対象書籍（ISBN・書名等）、該当箇所（ページ・行、版・刷、Kindle 位置等）、内容などを添えることができます。
3. 本サービス上の投稿は、原則として誰でも閲覧できる公開情報として扱われます。
4. 出版社その他の権利者は、運営者が認めた場合に、自らに関係する投稿に対して回答や対応状況の更新を行うことがあります。
5. 運営者は、本サービスの運営・維持のため、本サービス上に広告を掲載することがあります。広告の取り扱い（Cookie・アクセス解析等を含む）の詳細は、プライバシーポリシーに定めるとおりとします。

## 第2条（本規約への同意）

1. ユーザーは、本サービスを利用することにより、本規約に同意したものとみなされます。
2. 運営者は、本規約のほか、本サービス上で個別に定めるガイドライン等を本規約の一部として扱うことがあります。

## 第3条（アカウント登録）

1. 本サービスへの投稿には、メールアドレスによるアカウント登録が必要です。認証基盤には外部サービス（Supabase Authentication）を利用します。
2. ユーザーは、登録時に正確な情報を提供し、これを最新の状態に保つものとします。

4. 未成年者が本サービスを利用する場合は、親権者その他の法定代理人の同意を得たうえで利用するものとします。

## 第4条（表示名等の公開）

1. ユーザーが設定した表示名は、投稿に紐づいて公開されます。
2. ユーザーは、表示名その他の公開される情報に、第三者の権利を侵害する情報や本人を一意に特定し得る不要な個人情報を含めないものとします。

## 第5条（退会）

2. 退会にあたり、運営者は、ユーザーの認証情報および登録メールアドレス・表示名等の個人を特定し得る情報（以下「個人情報」といいます）を削除または匿名化します。
