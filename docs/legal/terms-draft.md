# Errata Hub 利用規約

本利用規約（以下「本規約」といいます）は、個人として本サービスを運営する nkn-ms（以下「運営者」といいます）が提供する「Errata Hub」（以下「本サービス」といいます）の利用条件を定めるものです。利用者（以下「ユーザー」といいます）は、本規約に同意のうえ本サービスを利用するものとします。

## 第1条（本サービスの概要）

1. 本サービスは、技術書をはじめとする出版物について、読者が発見した**正誤情報（誤字・脱字・記載の誤り等）および改善提案（より分かりやすい表現の提案等）、その他の気づき**を投稿し、共有するための公開型のユーザー投稿サービスです。
2. 投稿には、対象書籍（ISBN・書名等）、該当箇所（ページ・行、版・刷、Kindle 位置等）、内容などを添えることができます。
3. 本サービス上の投稿は、原則として誰でも閲覧できる公開情報として扱われます。
4. 出版社その他の権利者は、運営者が認めた場合に、自らに関係する投稿に対して回答や対応状況の更新を行うことがあります。

## 第2条（本規約への同意）

1. ユーザーは、本サービスを利用することにより、本規約に同意したものとみなされます。
2. 運営者は、本規約のほか、本サービス上で個別に定めるガイドライン等を本規約の一部として扱うことがあります。

## 第3条（アカウント登録）

1. 本サービスへの投稿には、メールアドレスによるアカウント登録が必要です。認証基盤には外部サービス（Supabase Authentication）を利用します。
2. ユーザーは、登録時に正確な情報を提供し、これを最新の状態に保つものとします。
3. ユーザーは、自己のアカウント（ログイン情報を含む）の管理責任を負い、第三者に利用させてはなりません。アカウントの管理不十分による損害の責任はユーザーが負うものとします。
4. 未成年者が本サービスを利用する場合は、親権者その他の法定代理人の同意を得たうえで利用するものとします。

## 第4条（表示名等の公開）

1. ユーザーが設定した表示名は、投稿に紐づいて公開されます。
2. ユーザーは、表示名その他の公開される情報に、第三者の権利を侵害する情報や本人を一意に特定し得る不要な個人情報を含めないものとします。

## 第5条（退会）

1. ユーザーは、本サービス所定の方法によりいつでも退会できます。
2. 退会にあたり、運営者は、ユーザーの認証情報および登録メールアドレス・表示名等の個人を特定し得る情報（以下「個人情報」といいます）を削除または匿名化します。
3. **退会後も、ユーザーが過去に行った投稿は、投稿者を「退会済みユーザー」と表示する匿名化された形で本サービス上に残ります。** これは、投稿された正誤情報等が他の利用者にとって有用な共有資産であることを踏まえた取り扱いであり、ユーザーは登録および投稿の時点でこれに同意するものとします。
4. 投稿そのものの削除を希望する場合の取り扱いは、第8条および本サービスの運用に従います。

## 第6条（投稿コンテンツの取り扱いと権利）

1. ユーザーが投稿したコンテンツ（テキスト、画像、指摘内容等。以下「投稿コンテンツ」といいます）の著作権その他の権利は、**投稿したユーザー、または当該コンテンツの正当な権利者（出版社・著者等を含む）に帰属します。** 運営者は投稿コンテンツの著作権を取得しません。
2. ユーザーは、運営者に対し、本サービスの提供・維持・改善・広報に必要な範囲で、投稿コンテンツを**無償かつ非独占的に、複製・公開・送信・表示・編集（表示上の整形・軽微な修正・要約等）する権利**を許諾するものとします。本許諾は、退会後も第5条第3項により残存する投稿コンテンツについて存続します。
3. ユーザーは、投稿コンテンツが第三者の著作権・商標権・プライバシー・名誉その他の権利を侵害しないこと、および自らが投稿する正当な権限を有することを保証するものとします。
4. 投稿コンテンツは、出版物の該当箇所を示すために必要かつ相当な範囲での引用にとどめ、書籍本文等の不必要な転載を行わないものとします。

## 第7条（禁止事項）

ユーザーは、本サービスの利用にあたり、以下の行為をしてはなりません。

1. 法令または公序良俗に違反する行為
2. 第三者または特定の個人・団体に対する誹謗中傷、名誉毀損、侮辱、嫌がらせ
3. 第三者の著作権・商標権・プライバシー権その他の権利を侵害する行為（書籍本文等の不当な転載を含む）
4. 虚偽の情報、事実に反する内容、または合理的根拠を欠く断定的な指摘を投稿する行為
5. 他人になりすます行為、または虚偽の所属（出版社・著者等）を称する行為
6. 本サービスの運営を妨害する行為、不正アクセス、過度な自動アクセス（スクレイピング・ボット等）
7. 本サービスを、対象出版物の正誤・改善に関する情報共有という目的を逸脱して利用する行為（単なる感想・宣伝・スパム等）
8. その他、運営者が不適切と合理的に判断する行為

1. 運営者は、投稿コンテンツが本規約に違反すると判断した場合、または運営上必要と判断した場合、ユーザーへの事前通知なく、当該投稿コンテンツを削除し、または非表示にすることができます。

3. 運営者は、投稿コンテンツの削除・存置について、特定の対応を行う義務を負うものではありません。
