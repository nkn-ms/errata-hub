# Errata Hub プライバシーポリシー

【要記入：運営者名称】（以下「運営者」といいます）は、運営するサービス「Errata Hub」（以下「本サービス」といいます）における利用者の個人情報を、以下の方針に基づいて取り扱います。

## 第1条（基本方針）

運営者は、個人情報の保護に関する法令その他の規範を遵守し、利用者の個人情報を適切に取り扱います。

## 第2条（取得する情報）

運営者は、本サービスの提供にあたり、以下の情報を取得します。

1. **アカウント情報**
   - メールアドレス（アカウント登録・認証・連絡のため）
   - 表示名（投稿に紐づいて公開されます）
   - パスワードは認証基盤（Supabase Authentication）にてハッシュ化等の安全な形式で管理され、運営者が平文のパスワードを取得・閲覧することはありません。
2. **投稿に関する情報**
   - 投稿された正誤情報・改善提案等の内容、対象書籍、該当箇所、添付画像（実装時）など。これらは公開情報として扱われます。
3. **ログ情報**
   - 本サービスの稼働基盤（ホスティング・認証基盤等）が自動的に記録する IP アドレス、ブラウザの種類（ユーザーエージェント）、アクセス日時等の情報。
   - 本サービス内の操作ログ（管理者による操作の記録等。以下「監査ログ」といいます）。

## 第3条（利用目的）

運営者は、取得した情報を以下の目的で利用します。

1. 本サービスの提供、本人認証、アカウントの管理
2. 投稿の公開・表示・共有
3. パスワード再発行その他、本サービスの運営に必要な連絡
4. 不正利用の防止、セキュリティの確保、および本サービスの維持・改善
5. 利用規約に違反する行為への対応
6. 法令に基づく対応

## 第4条（第三者提供および委託）

1. 運営者は、法令で認められる場合を除き、利用者の同意なく個人情報を第三者に提供しません。
2. 運営者は、本サービスの提供に必要な範囲で、以下の外部サービスに個人情報の取り扱いを委託し、または本サービスの機能上これらを利用します。

   | 委託先・利用先 | 用途 | 取り扱われ得る情報 |
   |----------------|------|--------------------|
   | Supabase（認証・データベース基盤） | 認証、データ保存 | メールアドレス、表示名、投稿、ログ等 |
   | Vercel（ホスティング基盤） | 本サービスの配信、アクセスログ | IP アドレス、アクセス情報等 |
   | OpenBD | 書誌情報（書名・著者・出版社・書影）の取得 | ※利用者の個人情報は送信しません（書籍の ISBN 等のみ） |
   | Google Books API | 書誌情報・書影の取得 | ※利用者の個人情報は送信しません（検索語・ISBN 等のみ） |

3. 上記の委託先・利用先のサーバーは日本国外（米国等）に所在する場合があり、その場合、個人情報が外国に移転されることがあります。【要記入：越境移転に関する方針・同意文言の要否を確認】

## 第5条（Cookie 等の利用）

1. 本サービスは、ログイン状態の維持等、サービスの提供に必要な範囲で Cookie 等を使用します。
2. **本サービスは、現時点でアクセス解析ツールや広告目的の Cookie を使用していません。** 将来これらを導入する場合は、本ポリシーを改定し、その旨を周知します。

## 第6条（保存期間・退会時の取り扱い）

1. アカウント情報は、アカウントが存続する間、保有します。
2. 監査ログ・アクセスログは、【要記入：保存期間の方針】に従って保有し、期間経過後に削除します。
3. 利用者が退会した場合、運営者は、認証情報および登録メールアドレス・表示名等の個人を特定し得る情報を削除または匿名化します。
4. **退会後も、利用者の過去の投稿は、投稿者を「退会済みユーザー」と表示する匿名化された形で本サービス上に残ります**（利用規約 第5条参照）。匿名化された投稿は、特定の個人を識別できる情報を含まないものとして扱います。

## 第7条（開示・訂正・利用停止等の請求）

1. 利用者は、自己の個人情報について、開示・訂正・追加・削除・利用停止・第三者提供の停止を請求することができます。
2. 前項の請求は、第9条の問い合わせ窓口にて受け付けます。運営者は、本人からの請求であることを確認のうえ、法令に従い合理的な期間内に対応します。
3. アカウント情報の一部（メールアドレス・表示名等）は、本サービス上の操作によって利用者自身が変更・削除（退会）できます。

## 第8条（安全管理措置）

運営者は、個人情報の漏えい、滅失または毀損の防止その他の安全管理のために、認証基盤・ホスティング基盤の提供する保護機能の活用、アクセス権限の制限、秘密情報（認証用キー等）の適切な管理等、合理的な措置を講じます。
