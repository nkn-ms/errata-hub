# Errata Hub プライバシーポリシー

個人として本サービスを運営する nkn-ms（以下「運営者」といいます）は、運営するサービス「Errata Hub」（以下「本サービス」といいます）における利用者の個人情報を、以下の方針に基づいて取り扱います。

## 第1条（基本方針）

運営者は、個人情報の保護に関する法令その他の規範を遵守し、利用者の個人情報を適切に取り扱います。

## 第2条（取得する情報）

運営者は、本サービスの提供にあたり、以下の情報を取得します。

1. **アカウント情報**
   - メールアドレス（アカウント登録・認証・連絡のため）
   - 表示名（投稿に紐づいて公開されます）
   - パスワードは認証基盤（Supabase Authentication）にてハッシュ化等の安全な形式で管理され、運営者が平文のパスワードを取得・閲覧することはありません。
   - 利用規約に同意した日時と、その時点の規約の版（同意の記録として保存します。公開されません）
2. **投稿に関する情報**
   - 投稿された正誤情報・改善提案等の内容、対象書籍、該当箇所、添付画像（実装時）など。これらは公開情報として扱われます。
3. **ログ情報**
   - 本サービスの稼働基盤（ホスティング・認証基盤等）が自動的に記録する IP アドレス、ブラウザの種類（ユーザーエージェント）、アクセス日時等の情報。
   - 本サービス内の操作ログ（管理者による操作の記録等。以下「監査ログ」といいます）。
4. **アクセス解析・広告に関する情報**
   - アクセス解析ツール、および（広告を掲載する場合）広告配信事業者を通じて取得される、閲覧ページ・参照元・おおよその地域・端末種別等の情報（詳細は第5条）。

## 第3条（利用目的）

運営者は、取得した情報を以下の目的で利用します。

1. 本サービスの提供、本人認証、アカウントの管理
2. 投稿の公開・表示・共有
3. パスワード再発行その他、本サービスの運営に必要な連絡
4. 不正利用の防止、セキュリティの確保、および本サービスの維持・改善
5. 利用規約に違反する行為への対応
6. 利用状況の把握・分析による本サービスの改善（アクセス解析）
7. 広告の配信および効果測定（本サービスが広告を掲載する場合）
8. 法令に基づく対応

## 第4条（第三者提供および委託）

1. 運営者は、法令で認められる場合を除き、利用者の同意なく個人情報を第三者に提供しません。
2. 運営者は、本サービスの提供に必要な範囲で、以下の外部サービスに個人情報の取り扱いを委託し、または本サービスの機能上これらを利用します。

   | 委託先・利用先 | 用途 | 取り扱われ得る情報 |
   |----------------|------|--------------------|
   | Supabase（認証・データベース基盤） | 認証、データ保存 | メールアドレス、表示名、投稿、ログ等 |
   | Vercel（ホスティング基盤） | 本サービスの配信、アクセスログ | IP アドレス、アクセス情報等 |

   なお、書籍の書誌情報・書影は外部の書籍データベース（OpenBD・Google Books）から取得しますが、その際に利用者の個人情報（氏名・メールアドレス等）を送信することはありません（送信するのは書籍の ISBN・検索語のみです）。

3. 上記の委託先・利用先のサーバーは日本国外（米国等）に所在する場合があり、その場合、個人情報が外国に移転されることがあります。利用者は、本サービスを利用することにより、本サービスの提供に必要な範囲で、これらの外国に所在する委託先・利用先において個人情報が取り扱われることに同意するものとします。

## 第5条（Cookie・アクセス解析・広告／外部送信について）

1. 本サービスは、ログイン状態の維持等、サービスの提供に必要な範囲で Cookie 等を使用します。

2. **アクセス解析**：本サービスは、利用状況の把握・改善のため、アクセス解析ツール「Vercel Web Analytics」を使用します。同ツールは **Cookie を使用せず**、個人を直接特定しない形で集計されたアクセス情報（閲覧ページ、参照元、おおよその地域、端末種別等）を取得します。

3. **広告**：本サービスは、その運営の維持のため、第三者配信の広告サービス（Google AdSense 等）を利用して広告を掲載する場合があります。広告を掲載する場合、当該広告事業者は、利用者の興味・関心に応じた広告（パーソナライズ広告）を表示する目的等で Cookie 等を使用し、本サービスへのアクセス情報を取得することがあります。
   - 利用者は、Google の広告設定ページ（ https://adssettings.google.com/ ）等から、パーソナライズ広告を無効にすることができます。
   - 第三者配信事業者による Cookie の利用については、各事業者のプライバシーポリシーをご確認ください。

4. **外部送信について**：本サービスの利用にあたり、利用者の端末から外部事業者へ送信される情報の概要は以下のとおりです。

   | 送信先 | 送信され得る情報 | 目的 | Cookie |
   |--------|------------------|------|--------|
   | Vercel Web Analytics | 閲覧ページ・参照元・おおよその地域・端末種別等の集計情報 | 利用状況の分析・改善 | 使用しない |
   | Google（AdSense 等の広告配信）※広告掲載時のみ | アクセス情報、広告識別のための Cookie 情報 | 広告配信・効果測定 | 使用する |

5. 欧州経済領域（EEA）・英国その他、適用される法令により事前の同意が必要とされる地域の利用者に対しては、当該法令に従い、パーソナライズ広告の表示等について同意取得の手段を講じます。

6. 本サービスは、上記以外に利用者を追跡することのみを目的とした Cookie を使用しません。アクセス解析・広告の利用内容に重要な変更があった場合は、本ポリシーを改定し、その旨を周知します。

## 第6条（保存期間・退会時の取り扱い）

1. アカウント情報は、アカウントが存続する間、保有します。
2. 監査ログ・アクセスログは、その保有の必要がなくなった後、90日を目安に削除するよう努めます（自動削除の仕組みは順次整備します）。

4. **退会後も、利用者の過去の投稿は、投稿者を「退会済みユーザー」と表示する匿名化された形で本サービス上に残ります**（利用規約 第5条参照）。匿名化された投稿は、特定の個人を識別できる情報を含まないものとして扱います。

3. 表示名の変更、およびアカウントの削除（退会）は、本サービス上の操作によって利用者自身が行えます。
